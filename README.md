# Практика API — Stepik

[Скачать коллекцию Postman](postman/petstore-stepik.postman_collection.json)

Коллекция содержит 20 запросов Swagger Petstore, сгруппированных по pet, store и user. Формат: Postman Collection v2.1.

## Запуск

1. Скачайте JSON и импортируйте через Import в Postman.
2. Задайте собственные `petId`, `orderId`, `username` и тестовый `password` в Variables.
3. Создайте свои тестовые данные, затем запускайте необходимые запросы. Для uploadImage выберите файл вручную.
4. Запросы удаления выполняйте только для собственных тестовых данных.

Проверки: статус из документации, отсутствие 5xx и время ответа менее 5000 мс. Порог времени — пример, его нужно адаптировать под требования.

Коллекция подготовлена по публичной схеме Petstore. Полный прогон всех 20 методов не выполнялся. Отдельно подтверждены негативный POST с некорректным JSON, создание и обновление питомца через POST/PUT, а также GET поиска по статусу sold. Значения переменных — учебные примеры, секретов в репозитории нет.
